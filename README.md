# NoTuMa
Novel To Manga Converter

## Overview
NoTuMa is a tool that converts novels into manga.

### Reasons for discontinuing

1. The project has gone out of hand.
1. There's a limit to how long you can keep asking the AI to generate code that you have not spent time on.
1. The stack is boring
1. NoTuMa will revive as a new project with a new stack and carefully planned architecture
